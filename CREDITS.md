# NULL SHIFT — asset credits

Original unofficial Matrix-inspired browser game. Not an official Matrix product and not affiliated with its rights holders. Game code, interface, procedural buildings, props, synthesized audio and integration were created for this project. The title artwork is an AI-generated illustration; in-game visuals are rendered in real time.

## Character models and animations

Microsoft Rocketbox: Business_Male_01 and Business_Male_03, their head/body/hand textures and idle, neutral walk and neutral run animations. Optimized textures, added sunglasses, adapted materials and procedural weapon poses for this game. MIT License, copyright Microsoft Corporation.

- Source: https://github.com/microsoft/Microsoft-Rocketbox
- License: https://github.com/microsoft/Microsoft-Rocketbox/blob/master/LICENSE.md
- Exact license included at assets/ROCKETBOX-LICENSE.txt.
