# NULL SHIFT

**[Play online](https://mkristof64.github.io/null-shift/)** · **[Download the offline HTML](download/NULL-SHIFT.html)**

Mátrix ihlette, két összekapcsolt küldetésből álló akciójáték asztali Chrome-hoz.

Open `index.html` in Chrome. All graphics, code, and audio are local: no installation, account, API key, or internet connection is required. The separately supplied `NULL-SHIFT.html` combines the entire game into one portable file.

## Mission

Törd fel a három zöld jeladót: állj melléjük, és tartsd lenyomva az E billentyűt. Ezután térj vissza a világító EXIT telefonfülkéhez. Használj fedezéket és időlassítást az ügynökök ellen; a zöld töredékek életerőt és fókuszt töltenek vissza. Minden feltört jeladó 25 életerőt ad és feltölti a fókuszt. A küldetés előrehaladtával erősödik az ellenállás.

## Mission 02 — Last Train

Az első pálya sikeres telefonos kijutása feloldja a második küldetést. A CONTINUE TO MISSION 02 gomb megnyitja a küldetés eligazítását. A feloldás ezen az eszközön, ebben a böngészőben megmarad; utána a főmenü MISSION választójából is elindítható.

Mara Central föld alatti állomásán lődd szét az A és B világító energiagömböt (egyenként három találat). A leeresztett pajzs mögül az E gombot nyomva tartva szerezd meg az adathordozót. Vidd a CALL terminálhoz az 1-es peronon, és tartsd nyomva az E-t. Éld túl a 35 másodperces rajtaütést, majd menj a zöld BOARD jelhez, engedd fel és tartsd újra nyomva az E-t a felszálláshoz. Az érkezési idő szünet alatt megáll; az időlassítás mellett 35 aktív játék-másodperc marad.

A restart mindig az aktuális pályát kezdi újra. Mindkét pálya külön rekordot tárol. A második pálya boltozatos mennyezetet, csempézett falakat és peront, oszlopokat, padokat, világító állomástáblákat, síneket és beérkező, ajtóit nyitó szerelvényt tartalmaz. A táblák és a HUD az aktuális feladatot követik.

## Controls

| Control | Action |
| --- | --- |
| WASD | Mozgás |
| Egér | Körülnézés |
| Bal egérgomb | Lövés; nyomva tartva sorozatlövés |
| Shift | Időlassítás nyomva tartva |
| Space | Ugrás; a levegőben újra megnyomva dupla ugrás |
| Q | Kitérés a mozgás irányába |
| R | Újratöltés |
| E | Közeli jeladó feltörése nyomva tartva |
| Escape vagy P | Szünet |

Click the game if Chrome needs to capture the mouse. If mouse capture is unavailable, hold the mouse button and drag to aim. Touch controls are available on devices with a coarse pointer, though the experience is designed for a desktop keyboard and mouse.

The menu offers three difficulties, a performance graphics setting, and audio controls. The best score and graphics/audio preferences are saved on this device when browser storage is available.

## Visual and audio pack

Részletes, textúrázott Microsoft Rocketbox embermodellek csontvázas járásanimációval, arctextúrákkal, öltönyökkel és napszemüveggel. A procedurális város különböző homlokzatokat, ablakkereteket, megvilágított ablakokat, párkányokat, antennákat és tetőszerkezeteket kapott. A tetőn PBR beton- és téglafelületek, szellőzőrácsok, víztorony, reflektorok, lefolyók és részletes telefonfülke található.

Eső, magas minőségben síkbeli tükröződés, dinamikus fények és árnyékok, bloom, időlassításkor digitális kód, részletes belső nézetű fegyver, fizikai lövedékek és saját szintetizált hangok egészítik ki. A fotószerű nyitókép generált illusztráció; maga a játék valósidejű 3D grafika.

Chrome must support WebGL and graphics acceleration. Choose VISUALS: PERFORMANCE if needed. This is an original fan-inspired game, not an official Matrix product.
